# Numerical reproduction

The active workflow requires only NumPy and matplotlib, as listed in the repository-root `requirements.txt`. All paths are resolved from the scripts' locations, so outputs stay inside the repository.

## Entry points and run order

Run from the repository root:

```bash
python code/generate_figures.py
```

This wrapper first calls `revision_numerics.py` to calculate and render the baseline comparisons, then calls `polish_analysis.py` for the added reference-only bound, transient ceiling, tolerance transition, and short-time scaling. The wrapper and both calculation scripts accept `--compute-only` and `--plot-only`.

```bash
python code/generate_figures.py --plot-only
python code/generate_figures.py --compute-only
```

Plot-only reproduction reads the included archive-local CSV and JSON files in `data/`. It does not require the surrounding submission package or a separately calculated exact trajectory. To run individual parts:

```bash
python code/revision_numerics.py
python code/polish_analysis.py
python code/generate_approximation_map.py
```

The additional analysis requires baseline CSVs already included here or regenerated by `revision_numerics.py`. Running it alone avoids rewriting the large baseline cutoff CSV. The approximation-map entry point only draws the schematic. Earlier inactive implementations are not included.

## Model and baseline calculation

The rotating-frame single-excitation Hamiltonian has a central state coupled to discrete detunings. Its spectral representation is evaluated in chunks; no time integration of the Schrödinger equation is used. Roots and central-state eigenweights of the arrowhead matrix are computed by bisection and checked independently against NumPy's dense eigensolver at 32 and 256 modes.

Uniform midpoint baths use a finite Lorentzian band with W = 16, Λ = 2, ω₀ = 10, and γ/Λ = 0.01, 0.04, 0.10, and 0.20. Mode counts are 32, 64, 128, and 256; the baseline coupling is γ = 0.08. All time units set ℏ = 1. No random seeds, fit procedures, or statistical sampling are used.

The continuous finite-band reference is approximated by Gauss–Legendre quadrature at 512, 768, and 1024 nodes. The final curve uses 1024 nodes, with convergence against 768 nodes and uniform grids. This is a numerical quadrature reference, rather than an analytic continuous-bath solution. The finite bandwidth is retained.

The first tolerance crossing is sought starting at t = 0, sampled on grids with spacing at most 0.01 and 0.005, and refined using the analytic spectral sum and bisection. The earliest sampled bracket agrees under grid halving in every reported case. A first exit defines a contiguous interval of accuracy from the initial state; subsequent re-entry does not extend that interval.

The cutoff residual is evaluated from t = 0, including the early missing-generator (initial-slip) term. Its speed estimate uses a trailing interval [max(0, t − τc), t], never future samples. A half-step margin based on |c″| ≤ Σj gj² covers intersample speed variation. Moment and tail integrals use trapezoidal quadrature. The weighted propagation integral uses a stable recurrence for a piecewise-linear integrand and is checked by halving the residual grid spacing from 0.0025 to 0.00125. These checks support numerical evaluation of the analytic inequality; they are not formal interval-arithmetic certification.

The cutoff decay rate κc is calculated from the finite bath and is distinct from γ/2. The Markov population-error bound includes this rate mismatch explicitly. Exceeding a tolerance means that the conservative bound no longer guarantees accuracy; it is not evidence that the observed error has exceeded that tolerance.

## Additional reference-only comparison

`reference_only_bound()` in `polish_analysis.py` directly constructs the uniform detunings and coupling squares. It does not call `Bath`, diagonalize a Hamiltonian, or evaluate the exact target amplitude. For the prescribed amplitude m(t) = exp(−γt/2), it evaluates its residual dM = m′ + C * m from the finite exponential kernel. The identity c − m = −c * dM, together with the invariant-sector bound |c| ≤ 1, gives |c − m| ≤ E(t) = ∫₀ᵗ |dM(s)| ds. Intersecting the amplitude interval [m − E, m + E] with [0, 1] gives the population bound. Its use is restricted to this exact scalar convolution problem. The exact amplitude is evaluated separately for validation and the observed first-exit comparison; it is not an input to the reference-only bound.

The residual itself is an analytical finite sum. The integral of its modulus uses composite trapezoidal quadrature at steps 0.0025 and 0.00125 over [0, 125]. The final saved bound uses the finer evaluation sampled at every second grid point, while the summary's endpoints use the full fine grid. Endpoints are linearly interpolated within the first sampled crossing bracket. This is converged numerical evaluation of an analytical inequality, not interval-arithmetic certification. Hardware-dependent timings distinguish bound evaluation from exact-trajectory validation; no computational speedup is claimed.

The continuum transient ceiling is δ*(γ) = max₀≤t≤80 |PW(t) − PM(t)| at the fixed finite bandwidth. The horizon 80 lies below 0.8 times the 256-mode rephasing time, 100.531. Maxima are found on a 0.01 time grid and locally refined in their sampled brackets. Gauss orders 768 and 1024 are compared over this full horizon at all four couplings. The dense tolerance scan uses 256 modes, explicitly inserts the refined finite-grid early maximum into its bracketing grid, and plots the early and late first-exit branches separately. It does not interpolate across their jump. The small-tolerance study checks γtδ/δ → 1.
